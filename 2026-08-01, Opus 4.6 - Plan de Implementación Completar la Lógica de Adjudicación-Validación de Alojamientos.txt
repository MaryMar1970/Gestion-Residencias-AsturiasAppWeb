### Componente 2: Servicio de Validación de Adjudicación (nuevo)

#### [NEW] backend/src/ResidenciaApp.Application/Services/AdjudicacionValidationService.cs

Servicio dedicado que centraliza TODA la lógica de validación antes de crear/actualizar una reserva:

```csharp
public interface IAdjudicacionValidationService
{
    Task<ValidacionResult> ValidarAsync(ValidarAdjudicacionDto dto);
}

public record ValidarAdjudicacionDto(
    Guid ResidenciaId,
    Guid? HabitacionId,
    Guid? TipoHabitacionId,
    string FechaEntrada,
    string FechaSalida,
    int NumPersonas,
    int NumNinos,
    string? DniHuesped,
    Guid? ExcluirReservaId
);

public record ValidacionResult(
    bool Valido,
    List<string> Errores,
    List<string> Avisos
);
```

**Reglas implementadas (en orden):**

1. **Capacidad por tipo** (GAP #1 y #6):
   ```
   IF tipo.PermiteNinos == false && numNinos > 0 → Error
   IF numPersonas > tipo.MaxAdultos → Error  
   IF numNinos > tipo.MaxNinos → Error
   IF numPersonas + numNinos > tipo.CapacidadMaxima → Error
   IF numPersonas < 1 → Error
   ```

2. **Fechas** (GAP #2):
   ```
   IF fechaEntrada >= fechaSalida → Error
   IF fechaEntrada < hoy → Error (no reservas en pasado)
   IF (fechaSalida - fechaEntrada).Days > tipo.MaxDiasEstancia → Error
   IF (fechaEntrada - hoy).Days > residencia.MaxDiasAntelacion → Aviso o Error
   IF fechas en período de cierre estacional → Error
   ```

3. **Separación entre estancias** (GAP #3):
   ```
   IF dniHuesped != null:
     Buscar últimas reservas del mismo DNI en la misma residencia
     IF alguna reserva existente tiene gap < minDiasSeparacion → Aviso
   ```

4. **Disponibilidad** (ya existe, se invoca):
   ```
   IF habitacionId != null:
     Reutilizar ComprobarSolapamientoAsync existente
   ```

## Diagrama: Flujo de Adjudicación con Validaciones

```mermaid
flowchart TD
    A[Usuario crea/edita reserva] --> B{¿Es bloqueo?}
    B -->|Sí| K[Solo validar solapes]
    B -->|No| C[Validar Capacidad]
    C --> D{PAX ≤ MaxAdultos?<br>Niños ≤ MaxNinos?<br>PermiteNinos?}
    D -->|No| E[❌ Error capacidad]
    D -->|Sí| F[Validar Fechas]
    F --> G{Estancia ≤ Max?<br>Antelación ≤ Max?<br>No cierre estacional?}
    G -->|No| H[❌ Error fechas]
    G -->|Sí| I[Validar Separación DNI]
    I --> J{Gap ≥ Min días?}
    J -->|No| L[⚠️ Aviso separación]
    J -->|Sí| K
    L --> K
    K --> M[Comprobar Solapes]
    M --> N{¿Habitación libre?}
    N -->|No| O[❌ Error solape]
    N -->|Sí| P[Calcular Evaluación/Prioridad]
    P --> Q[Calcular Resolución]
    Q --> R[Crear/Actualizar Reserva]
    R --> S[✅ Reserva guardada]
```
